System Architecture — CAN Bus Topology

⚡ Bus Rules & Grounding

  • • COMMON GROUND: All 4 boards must connect their GND pins together. Missing common ground causes frame corruption and silent RX failures.
  • • 120Ω TERMINATORS: Exactly two 120Ω resistors must be placed across CANH and CANL at the two physical ends of the line.
  • • BAUD RATE: Standard automotive 500 kbps.

🛡️ Fail-Safe Architectures

  • • Front BCM: If CAN link is lost for > 1.2s, board enters Fail-Safe Mode (forces Low Beams ON 100%, turns LD5 Red LED ON).
  • • Central Coordinator: Central ECU validates all user requests before executing. Rejects trunk commands if vehicle speed > 5 km/h.
  • • Smart Kick Trunk: Ultrasonic proximity trigger set to strictly ≤ 8cm to avoid false triggers while driving.

Central ECU — STM32F407 Discovery

The Central Master Coordinator. Ingests user commands from Qt (0x100–0x104), validates states, routes approved executions (0x200–0x211), and broadcasts state (0x300–0x304) and sync ticks (0x130).

⚙️ Internal Timers & Logic

• TIM6 (100ms): Master sample loop for ADC potentiometers, vehicle state broadcast (0x300), and Central Heartbeat (0x700).

• TIM7 (500ms): Turn Signal Synchronization Pulse (0x130 Blink Tick).

• Multi-beam Light Bitmask Accumulator: Central ECU dynamically accumulates active lights into EXEC_FRONT_LIGHTS (0x200) so DRL, Low Beam, High Beam, and Fog can stay lit concurrently.

⚠️ Critical Wiring Rule:

The F411 never touches the CAN wires. It communicates strictly through UART to the F103. If you connect PA2 to PA9 directly, you wired TX-to-TX and the heartbeat will die! Always wire PA2 → PA10 and PA3 → PA9.

🧳 Smart Kick Trunk Calibration

• Trigger Distance: Strictly calibrated to ≤ 8 cm (reduced from 15cm) to ensure hands-free kick opening without accidental road spray triggers.

• Safety Interlock: Central ECU unconditionally denies trunk opening if Vehicle Speed > 5 km/h or Gear is in Drive/Reverse.

💻 PC Serial Protocol

• Format: CAN:<ID_HEX>:<DLC>:<DATA_HEX>\r\n

• Example: CAN:100:2:0264\r\n (Commands Low Beam at 100% brightness)

• Handled automatically by Qt's CanBusGateway.cpp and our can_monitor.py tool.

🔨 Build & Flash Guide for Academic Verification

1. One-Click IDE Import

All projects use 100% relative include paths. The examining supervisor can clone anywhere (C:, D:, Mac, Linux) and import cleanly without missing-path errors:

  1. Open STM32CubeIDE → File → Import
  2. Select General → Existing Projects into Workspace
  3. Browse to repository root → Click Finish
  4. Click Project → Build All (Ctrl+B)

2. Live Bus Monitoring Tool

We provide a dedicated Python script that decodes 100% of CAN v3.0 messages without spamming duplicate heartbeats:

python front_bcm_firmware/can_monitor.py COM9

• Instantly logs all user button commands, approvals, and fault alerts with millisecond timestamps.
